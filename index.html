01

Что такое OSINT?

// osint_intro.sh
root@osint:~$ cat definition.txt
> Загрузка определения...
 
OSINT — это сбор и анализ информации из
открытых, общедоступных источников для
получения разведывательных данных.
 
root@osint:~$ whoami

// ОПРЕДЕЛЕНИЕ OSINT (Open Source Intelligence) — разведка по открытым источникам. Методология сбора данных из публично доступных ресурсов: социальных сетей, новостей, баз данных, спутниковых снимков, форумов, архивов, DNS-записей и любых других источников, не требующих взлома или получения скрытого доступа.
02

Типы разведки

◈ WEB

WEBINT

Разведка в открытом вебе: индексируемые страницы, архивы, кешированные версии, метаданные документов, скрытые директории, утечки паролей.

WEB INTELLIGENCE
◈ SOC

SOCMINT

Анализ социальных сетей: профили, связи, геотеги, публикации, скрытые аккаунты, анализ поведения и графа контактов.

SOCIAL MEDIA INT
◈ GEO

GEOINT

Геопространственная разведка: спутниковые снимки, геолокация фотографий, карты, анализ местности, перемещения объектов.

GEO INTELLIGENCE
◈ DNS

TECHINT

Технический OSINT: WHOIS, DNS-записи, сертификаты SSL, открытые порты через Shodan, поиск уязвимостей, отпечатки систем.

TECHNICAL INT
◈ HUM

HUMINT (open)

Открытый сбор о людях: публичные записи, судебные базы, ЕГРЮЛ, выписки из реестров, публикации, паспортные базы утечек.

HUMAN INT
◈ DRK

DARKINT

Мониторинг даркнета: утечки данных, форумы, слитые базы, продажа доступов, упоминания организаций и персон на закрытых площадках.

DARKNET INT

04

Процесс расследования

01

ПЛАНИРОВАНИЕ И ЦЕЛЕПОЛАГАНИЕ

Определение задачи: кто или что является объектом? Какие данные нужны? Установка границ исследования и правовых ограничений. Создание плана с указанием источников и методов сбора.

SCOPE TARGETING LEGAL CHECK
02

СБОР ДАННЫХ (COLLECTION)

Активный и пассивный сбор данных из всех доступных источников: поисковые системы, социальные сети, публичные реестры, базы данных, архивы, технические данные DNS/WHOIS.

PASSIVE RECON ACTIVE RECON DORKING
03

ОБРАБОТКА И ВЕРИФИКАЦИЯ

Проверка достоверности найденных данных. Перекрёстный анализ между источниками. Фильтрация шума. Установление временных меток и актуальности информации.

CROSS-CHECK VERIFICATION TIMELINE
04

АНАЛИЗ И ВИЗУАЛИЗАЦИЯ

Построение графов связей, временных линий, географических карт. Выявление паттернов, аномалий и скрытых связей. Синтез разрозненных данных в цельную картину.

LINK ANALYSIS MAPPING PATTERN REC
05

ОТЧЁТ И ВЫВОДЫ

Формирование структурированного отчёта с источниками, методологией и выводами. Разграничение фактов и предположений. Сохранение доказательной базы для возможного последующего использования.

REPORTING EVIDENCE CONCLUSIONS
⚠
// ЭТИКА И ЗАКОННОСТЬ

OSINT — это не взлом и не слежка. Работа только с публично доступными данными не нарушает закон, но может нарушать этику. Уважайте приватность, не собирайте данные о частных лицах без весомых оснований, соблюдайте GDPR и местное законодательство. Разведка должна служить общественному благу: журналистике, безопасности, исследованиям — но не преследованию или дискредитации людей.
